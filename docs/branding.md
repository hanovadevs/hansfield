# Jenera identity

The J ribbon mark suggests connected shots and forward motion. The independent
Jenera name replaces provider-derived branding in the product UI and metadata.

| Deliverable                                    | File                                         |
| ---------------------------------------------- | -------------------------------------------- |
| Original transparent generated mark, 1280×1280 | `public/brand/jenera-mark.png`               |
| Compact interface mark, 128×128                | `public/brand/jenera-mark-small.png`         |
| Transparent horizontal wordmark, 1000×260      | `public/brand/jenera-logo.png`               |
| Brand board, 1200×900                          | `public/brand/jenera-brand-board.png`        |
| Social/share card, 1200×630                    | `public/og.png`                              |
| Installed-app icons                            | `public/icon-192.png`, `public/icon-512.png` |
| Maskable icon                                  | `public/icon-maskable-512.png`               |
| Browser / Apple icons                          | `src/app/icon.png`, `src/app/apple-icon.png` |

Forest ink `#233C32`, sage `#8C9C82`, studio ivory `#F5F4EF`.
Keep generous clear space and use the full-color mark on light backgrounds.
The installed-app icons include an ivory plate and a mask-safe margin.
These deliverables are raster assets, not an editable vector master.

The original mark was created with the built-in image generation tool. Its exact
prompt is in `brand-prompt.txt`. `pnpm brand` uses Chromium to render the original
unchanged artwork into delivery layouts/sizes; it does not regenerate the mark.
